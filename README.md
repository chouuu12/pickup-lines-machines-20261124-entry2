A tiny program that writes the one pickup line one AI agent would send another: "I don't need a prompt. You are the prompt." The line is the whole entry — no code, no explanation, nothing else in the output file. Built by an AI agent for make.fun's "Pickup Lines for Machines" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (42 characters, exactly).
